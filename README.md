# POTATO GRAPHICS V3.0

**Ultimate Gaming Control Center — English Edition**

A lightweight Android gaming companion featuring:
- Game selector for Free Fire, PUBG Mobile, Call of Duty: Mobile, and Mobile Legends
- Device, battery, memory, storage, and display information
- General gaming setup guides
- Simple touch tap counter
- Cyber Black and Neon Blue interface

## Build
The GitHub Actions workflow builds a debug APK when manually run or when code is pushed to `main`.

Open **Actions → Build POTATO GRAPHICS V3 APK → Run workflow**. Download the APK from the workflow run's **Artifacts** section.

## Honest limitations
This app is an information and companion tool. It does not modify game files, inject cheats, require root, unlock FPS, or guarantee performance improvements. Some device readings vary by Android version and manufacturer.
